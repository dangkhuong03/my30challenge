# Designed Workload Budget

This is a design budget, not observed learner evidence. Gate 4 must replace assumptions with pilots. Minimum sessions preserve momentum but cannot produce daily PASS when mandatory evaluators remain incomplete.

| Day type | Target | Allocation | Designed decision |
|---|---:|---|---|
| Baseline/final | 210m | attempt 150, scoring/evidence 60 | fixed |
| Standard content | 120–150m | retrieval 15, instruction/reconstruction 35–45, independent/transfer 45–60, feedback/evidence 25–30 | feasible candidate |
| Dense derivation/modelling | 180m | retrieval 15, two mechanism blocks 90, transfer 40, feedback/evidence 35 | feasible candidate |
| Day 6 high-density statistics | 240m | probability cluster 45, estimation cluster 75, inference cluster 45, independent evaluators 45, feedback/evidence 30 | requires pilot |
| Day 20 high-density systems | 240m | correctness 55, capacity/limiter 55, product constraints 40, failure-transfer build 55, feedback/evidence 35 | requires pilot |
| Day 27 high-density architecture | 240m | context/cost 50, tool/security topology 55, session/Goal lifecycle 55, integrated build 45, defense/evidence 35 | requires pilot |
| Weekly review | 150m | locked assessment 75–105, scoring/error taxonomy/recovery remainder | fixed |
| Capstone | 180m | architecture 90, adversarial traces 45, defense/revision 45 | requires pilot |

If a pilot exceeds target or loses reasoning quality, the remedy is redistribution, prerequisite compression or a declared longer session—not hiding mandatory work in stretch or weakening evaluators.
